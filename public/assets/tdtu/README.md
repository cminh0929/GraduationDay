# Tài nguyên hình ảnh Trường Đại học Tôn Đức Thắng (TDTU)

Thư mục này dùng để lưu trữ các tài nguyên ảnh chính thức của TDTU và ảnh cá nhân của Đặng Công Minh:

1. `logo-official-square.png`:
   - Logo chính thức được lấy trực tiếp từ `https://www.tdtu.edu.vn/sites/www/files/logo_2.png`.
2. `logo-official-header.png`:
   - Biểu trưng header được lấy trực tiếp từ `https://www.tdtu.edu.vn/sites/www/files/logo-dh_0.png`.
2. `portrait.jpg`:
   - Ảnh chân dung tân cử nhân Đặng Công Minh trong trang phục tốt nghiệp.
3. `campus.jpg`:
   - Ảnh kiến trúc khuôn viên trường Đại học Tôn Đức Thắng (19 Nguyễn Hữu Thọ).

Hệ thống đã có sẵn fallback SVG vector chính xác và giao diện chuẩn mực trong trường hợp các file ảnh chưa được thêm vào.
